# TEW v2

Fresh rebuild of Third Eye World, restarted from scratch across both the
backend and the client. This phase targets Android only — no iOS, no web.

- [`backend/`](backend) — Node/Fastify + Postgres, Android-only scope, Firebase Auth.
- [`android/`](android) — Kotlin/Compose app, shared core + two UI shells (radio-timeline, card-deck).

Both are design-stage only. No implementation yet.
